# MorphTrace for Cursor and VS Code

MorphTrace runs entirely inside the current workspace. It uses the standard VS Code extension API, so it is compatible with Cursor.

1. Copy `../../examples/morphtrace.grammar.json` to your workspace as `morphtrace.grammar.json`.
2. Select a surface form and run **MorphTrace: Analyze Selected Word**.
3. Run **MorphTrace: Generate Word Form** and enter a lemma plus a JSON feature bundle.

The included grammar is a synthetic demo. It is not linguistic documentation for a real language.
